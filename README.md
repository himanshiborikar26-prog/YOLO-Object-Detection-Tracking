# YOLO Object Detection and Tracking

## About the Project
This project uses YOLO and OpenCV to detect and track objects in real time using a camera.

## Features
- Real-time object detection
- Object tracking with IDs
- Confidence score display
- FPS and object count dashboard
- Object movement trails
- Line crossing counter
- Save detected images
- Generate CSV reports

## Technologies Used
- Python
- YOLO
- OpenCV
- ONNX Runtime
- NumPy
- Pillow

## Requirements
Install the required Python libraries using:

```bash
pip install -r requirements.txt
```

## How to Run
1. Open the project folder in VS Code.
2. Make sure the ONNX model file is present.
3. Run the following command:

```bash
python main.py
```

## Model
The project uses the `yolov8n (1).onnx` model.
